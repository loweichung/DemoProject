# アカウント管理システム (Next.js & TypeScript)

このプロジェクトは、Next.js と TypeScript を使用して構築された、アカウント作成およびアカウント照会機能を持つフロントエンドのデモンストレーションです。

## 概要

このプロジェクトの主な目的は、ユーザー入力の正確性を担保するための**バリデーション（認証・検証）機能**の実装に焦点を当てることです。以下の機能を試行しました：

- **アカウント新規作成**: 
  - 名前、性別、生年月日、メールアドレス、住所、パスワードの入力。
  - **バリデーション機能**: 空欄チェック、有効なメール形式の確認、および強力なパスワード要件（8文字以上、大文字・小文字・数字の混在）の強制。
  - **UIフィードバック**: 未入力や形式不備がある場合、入力項目が自動的に赤く表示されるリアルタイムフィードバックの実装。
- **アカウント照会**: 
  - 電話番号とメールアドレスによるアカウント情報の検索。
  - 照会完了後、登録メールアドレスへの通知を促すメッセージの表示。

## 使用技術

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Form Management**: React Hook Form
- **Validation**: Zod
- **Icons**: Lucide React
